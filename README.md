# نظام المبيعات والمشتريات - Arabic Sales & Purchasing System

نظام متكامل لإدارة المبيعات والمشتريات مبني باستخدام Microsoft Excel وPython.

## المميزات

- واجهة عربية كاملة مع دعم RTL
- إدارة العملاء والموردين
- إدارة المنتجات والمخزون
- فواتير المبيعات والمشتريات
- تتبع المدفوعات والمصروفات
- تقارير شاملة
- لوحة تحكم تفاعلية
- حماية وأمان متقدم
